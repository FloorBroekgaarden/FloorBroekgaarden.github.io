<p class="software-intro">I am committed to open science — releasing the code, data, and tools behind my research so that results can be reproduced, built upon, and extended by the community. Below is a list of software packages and data releases I have contributed to.</p>

<div class="software-item">
  <h3>1. STROOPWAFEL — Adaptive Importance Sampling for Rare Astrophysical Events</h3>
  <p class="software-meta">2019–2020</p>
  <p>Code and data for STROOPWAFEL, a method to efficiently sample rare astrophysical events using adaptive importance sampling. The original version (2019) samples from up to 3 dimensions; a PyPI extension (2020) by L. Khandelwal &amp; F.S. Broekgaarden extended this to 10 dimensions using generative adaptive importance sampling.</p>
  <div class="software-links">
    <a href="https://github.com/FloorBroekgaarden/STROOPWAFEL" target="_blank">GitHub</a>
    <a href="https://zenodo.org/record/3627403" target="_blank">Zenodo</a>
  </div>
</div>

<div class="software-item">
  <h3>2. Population Synthesis Simulation Data Sets</h3>
  <p class="software-meta">2021 · F.S. Broekgaarden · over 1,000 total downloads</p>
  <p>Several large data sets of population synthesis simulations of compact binary mergers (BHBH, BHNS, NSNS), generated with the COMPAS code. Publicly released to enable community comparisons and follow-up analyses.</p>
  <div class="software-links">
    <a href="https://doi.org/10.5281/zenodo.5178777" target="_blank">BHNS simulations (Zenodo)</a>
    <a href="https://doi.org/10.5281/zenodo.5189849" target="_blank">NSNS simulations (Zenodo)</a>
    <a href="https://doi.org/10.5281/zenodo.5651073" target="_blank">BHBH simulations (Zenodo)</a>
  </div>
</div>

<div class="software-item">
  <h3>3. COMPAS Stellar Evolution Code</h3>
  <p class="software-meta">2022 · COMPAS Collaboration; Riley, Jeff et al. incl. Broekgaarden, F.S.</p>
  <p>COMPAS (Compact Object Mergers: Population Astrophysics and Statistics) is a rapid binary population synthesis code for simulating the evolution of massive binary stars into compact object mergers. Published in the <em>Journal of Open Source Software</em> (JOSS).</p>
  <div class="software-links">
    <a href="https://compas.readthedocs.io/en/latest/" target="_blank">Documentation</a>
    <a href="https://github.com/TeamCOMPAS/COMPAS" target="_blank">GitHub</a>
  </div>
</div>

<div class="software-item">
  <h3>4. Rates of Compact Object Coalescences — Data Set</h3>
  <p class="software-meta">2022 · F.S. Broekgaarden, I. Mandel · over 4,000 downloads</p>
  <p>Data set accompanying the paper <em>Rates of Compact Object Coalescences</em>, containing merger rate predictions across a broad range of stellar evolution model assumptions.</p>
  <div class="software-links">
    <a href="https://doi.org/10.5281/zenodo.7017532" target="_blank">Zenodo</a>
  </div>
</div>

<div class="software-item">
  <h3>5. Mass Ratio Reversal Project — Data Set</h3>
  <p class="software-meta">2022 · F.S. Broekgaarden · over 100 downloads</p>
  <p>Data set from the Mass Ratio Reversal project, containing binary population synthesis results investigating how binary evolution can flip the mass ordering of black hole binaries.</p>
  <div class="software-links">
    <a href="https://doi.org/10.5281/zenodo.6978990" target="_blank">Zenodo</a>
  </div>
</div>

<div class="software-item">
  <h3>6. Gravitational Wave Visualizations — Data Set</h3>
  <p class="software-meta">2024 · F.S. Broekgaarden · over 100 downloads</p>
  <p>Data set and code accompanying gravitational-wave visualization projects, made publicly available for educational and outreach use.</p>
  <div class="software-links">
    <a href="https://doi.org/10.5281/zenodo.7793213" target="_blank">Zenodo</a>
  </div>
</div>

<div class="software-item">
  <h3>7. The Software Citation Station</h3>
  <p class="software-meta">2024 · Wagg, T., Broekgaarden, F., &amp; Gültekin, K.</p>
  <p>A tool that makes it easy to find and format proper citations for scientific software used in research. I conceived the research project idea and concept, contributed significant code, and developed the literature foundation behind the project. Tom Wagg (a student and collaborator in my group) was the lead developer. Published on Zenodo as v1.2.</p>
  <div class="software-links">
    <a href="https://www.tomwagg.com/software-citation-station/" target="_blank">Tool</a>
    <a href="https://github.com/TomWagg/software-citation-station" target="_blank">GitHub</a>
    <a href="https://doi.org/10.5281/zenodo.13225824" target="_blank">Zenodo</a>
  </div>
</div>
